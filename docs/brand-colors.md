# Sussegado — Brand Colors

Extracted from the live site's CSS custom properties (`index.html`), for handing to another Claude chat to build a full brandbook.

## Core palette

| Name | Hex | Role |
|---|---|---|
| Parchment | `#F6F2E9` | Background (site + share cards) |
| Ink | `#2B211B` | Primary body text |
| Accent (Teal) | `#13464E` | Primary CTA / links / "Our Menu" & "Our Story" headings / pricing |
| Teal (secondary) | `#1F4C4C` | Pronunciation notes, secondary small text |
| Gold | `#B8863B` | Dividers, decorative diamond marks, corner accents |

## Additional accent used once

| Name | Hex | Role |
|---|---|---|
| Deep Ink | `#29211C` | Active state on the EN/ES language toggle (secondary CTA, distinguished from the teal primary CTA) |

## Notes for the brandbook

- The icon (a *balcão* — Goan oyster-shell lattice window) is always drawn in Accent Teal (`#13464E`) with a Gold (`#B8863B`) diamond center.
- Accent Teal is the "primary action" color (buttons, links, active nav state). Deep Ink (`#29211C`) is used specifically as a "secondary action" color so the two CTA weights are visually distinct.
- Gold is decorative only — dividers and corner flourishes, never text or buttons.
- Background is a warm parchment, not pure white — this is a deliberate warmth throughout print and digital assets (site, PDF/PNG share cards, stickers, booklets).
